## ✨ Features

- Browse and explore recipes.
- Filter recipes by category.
- Filter recipes by meal type.
- Vegetarian recipe filtering using `isVeg`.
- View recipe details.
- Add new recipes using a form.
- Form validation.
- Add recipes to favourites.
- Favourites persist after refresh.
- Light Mode and Dark Mode.
- Responsive design for desktop, tablet and mobile.
- API integration for fetching recipe data.
- Navigation using React Router.
- Custom 404 Not Found page.

## 🚀 How to Run Locally

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/PadmashreeArunprasath/Recipe_Book
   ```

2. Navigate to the project directory:

   ```bash
   cd Recipe_Book
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Create a `.env` file in the root directory:

   ```env
   VITE_API_URL=https://dummyjson.com/recipes
   ```

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open the URL provided by Vite in your browser.
